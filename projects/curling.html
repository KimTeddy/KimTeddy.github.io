Overview

게임 진행 프로세스

PMOD 키패드를 활용하여 타이밍에 맞춰 위치, 스핀, 파워를 조작하는 FPGA 하드웨어 기반 게임입니다.

🏁

1. 세트 시작 & 스톤 세팅

키패드 1번을 눌러 게임을 시작하면 스톤이 좌우 왕복 이동을 시작합니다. 키패드 2번을 통해 시작 위치와 스핀 방향을 확정합니다.

⚡

2. 파워 게이지 제어

위치 설정 후 하단 파워 게이지가 좌우로 움직이며, 키패드 3번을 눌러 지시계를 멈춘 곳의 위치가 스톤의 초기 속력(파워)이 됩니다.

🧹

3. 스위핑 조작 (브룸)

이동 중 키패드 A/B를 연타하면 직진 방향 마찰력 감소 또는 스핀 방향 변화를 줍니다. 횟수 제한과 정지 상태 미작동 로직이 반영되었습니다.

💥

4. 물리 및 충돌 판정

스톤이 벽에 부딪히거나 다른 스톤과 충돌 시 반발하며 튕겨나가며, 수직 충돌 시 정지하는 디테일한 물리 알고리즘을 적용했습니다.

🎯

5. 과녁 점수 계산

모든 스톤 정지 후, 컬링 룰에 기반한 점수 계산 알고리즘(거리 비교 모듈)을 통해 과녁 중심에 가장 가까운 팀에 점수를 부여합니다.

🔄

6. 다음 세트 (FSM)

3세트로 구성된 게임 스테이트를 관리하며 키패드 D/F를 통해 점수를 이어가거나 완전 초기화할 수 있습니다.

Architecture

하드웨어 코드 아키텍처

Verilog HDL을 활용한 주요 모듈의 코드 설계 및 논리 구조입니다. GitHub 리포지토리의 실제 코드를 분석하여 작성되었습니다.

scoring.v FSM & Scoring Logic 
always @(posedge clk, posedge rst) begin
    if(rst) c_state <= WAIT;
    else    c_state <= n_state;
end

// 거리 기반 점수 계산 State Machine
always @(*) begin
    case (c_state)
        WAIT:    begin if(calc_trigger) n_state=ORDERSTART; else n_state=WAIT; end
        ORDER0:  begin n_state=ORDER1; end
        ...
        SCOREA0: begin if(order[0]%2==0 && max_count>=0) n_state=SCOREA1; else n_state=SCOREB0; end
    endcase
end

정교한 스테이트 머신(FSM) 설계

게임의 턴 진행, 스톤 투구 순서, 과녁 중앙과의 거리 계산, 그리고 랭킹 산정까지 복잡한 과정들을 유한 상태 기계(Finite State Machine)로 모델링했습니다. 클럭 엣지에 동기화되어 충돌 없이 순차적으로 실행되도록 제어 로직을 구현했습니다.

circle.v & distance_t.v Geometric Graphics 
// 픽셀 좌표(x,y)와 중심 좌표(cir_x,cir_y) 간의 거리 제곱
assign distance = (((cir_x-x)*(cir_x-x)) + ((cir_y-y)*(cir_y-y)));

// 반지름의 제곱과 비교하여 원 내부 픽셀 판정 (출력 제어)
assign circle_on = (cir_r*cir_r >= distance)? 1 : 0; 

// 동일한 로직을 응용한 스톤-타겟 거리 계산
assign distance_sq = (((target_x-stone_x)*(target_x-stone_x)) + 
                      ((target_y-stone_y)*(target_y-stone_y)));

기하학적 렌더링 및 연산 최적화

모니터 출력에 필요한 원 그리기(스톤, 타겟)와 점수 산정을 위한 거리 비교를 피타고라스 정리(x² + y² ≤ r²) 기반의 Combinational Logic으로 구현했습니다. 하드웨어에서 무거운 제곱근 연산을 생략하고 거리의 제곱값만으로 비교하여 자원을 크게 최적화했습니다.
