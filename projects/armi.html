Overview

프로젝트 개요

대한민국의 병력 부족과 무기 첨단화에 따라 군사 경계 시스템의 효율성 개선이 요구됩니다.

🎯

목적

기존의 24시간 병사 감시 체제를 보조·대체하여 저전력 AI 기반 분산형 경계 감시 시스템을 구현합니다.

⚡

저전력 설계

ARM의 Standby 모드와 저전력 실측으로 약 0.01Ω 센트 저항 전압 강하 측정 기반 초저전력 운영을 실현합니다.

🧠

온디바이스 AI

STM32에 Cube.AI를 활용하여 320×240 그레이스케일 이미지 기반 CNN 객체인식 모델을 내장하여 Edge에서 직접 추론합니다.

📡

RF 통신

nRF24L01+ 모듈로 Edge Device와 서버 PC 간 무선 통신을 구현하며, 감지된 이미지만 전송하여 대역폭을 절약합니다.

🔋

에너지 하베스팅

MPPT(Maximum Power Point Tracking) 회로와 태양광 패널을 사용하여 배터리 충전 효율을 극대화합니다.

🖥️

서버 & 모니터링

서버 PC에서 다수 Edge 디바이스의 이미지를 수신하고, CNN 기반 1:N 객체 인식을 실시간으로 수행합니다.

Low-Power Design

저전력 설계

실측 전력 소모 데이터 — 0.01Ω 센트 저항 전압 강하 + 전류계 측정

⚡

피크 소비 전력

RF 모듈 + 카메라 활성
3.7V × 150mA = 555mW

😴

대기 모드 전력

MCU Standby + PIR만 활성
3.7V × 1.43mA = 5.29mW

Standby 모드 전류 측정
0.01Ω 센트 저항 전압 강하: 1.5mV → 1.43mA
Active 모드 전류 측정
RF + Camera 활성 시: 14.3mV → ~150mA
전류 측정 상세
멀티미터 + PCB + LiPo 배터리 실측 환경

Standby Mode 동작

MCU는 Standby모드에서 PIR 센서를 통해 Wake Up합니다. 이벤트 발생 시 이미지를 촬영하고 CNN 모델로 객체를 인식합니다. 감지 시에만 이미지를 서버로 전송하고, 처리가 완료되면 다시 Standby 모드로 전환됩니다.

3.3V On/Off MOSFET 회로

MOSFET 회로를 구성하여 이미지 센서(OV2640)와 RF 모듈의 전원을 개별 제어하여 비활성 시 대기 전력을 완전히 제거합니다.
